# Code of Conduct

## Our Purpose

This repository is a learning-focused programming repository where people can practice programming languages, explore syntax, learn programming concepts, and contribute examples and exercises.

The goal of this Code of Conduct is to maintain a respectful, welcoming, and constructive environment for everyone who wants to learn or contribute.

Everyone participating in this repository is expected to follow these guidelines.

---

## Expected Behavior

Contributors and participants are expected to:

- Be respectful and professional.
- Treat other contributors with kindness.
- Be open to different approaches and opinions.
- Give constructive feedback.
- Accept constructive feedback respectfully.
- Keep discussions focused on the topic.
- Help beginners when possible.
- Ask questions when something is unclear.
- Explain technical disagreements with reasoning and examples.
- Respect the work and contributions of others.
- Give appropriate credit when using someone else's work.
- Keep the repository focused on programming and learning.

---

## Communication

When participating in:

- Issues
- Pull Requests
- Discussions
- Code reviews
- Comments
- Other repository-related communication

please communicate clearly and respectfully.

For example, instead of saying:

> "This code is bad."

Prefer:

> "This approach may be difficult for beginners to understand. We could simplify it by using..."

Technical criticism is welcome.

Personal criticism is not.

---

## Constructive Feedback

The purpose of feedback should be to improve the code, documentation, or learning experience.

Good feedback should:

- Explain what could be improved.
- Explain why it could be improved.
- Suggest an alternative when possible.
- Focus on the contribution rather than the person.
