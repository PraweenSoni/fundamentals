# Security Policy

## Supported Versions

This repository is primarily a programming learning repository.

Security fixes are applied to the current version of the repository where applicable.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ |
| Older versions | ❌ |

## Reporting a Security Vulnerability

If you discover a security vulnerability in this repository, please do not publicly disclose sensitive information in a GitHub Issue.

Instead, report the issue privately through the repository owner's contact method.

Please include:

- A clear description of the vulnerability.
- The affected file or directory.
- Steps to reproduce the issue.
- The potential impact.
- Any suggested fix, if available.

## Sensitive Information

Never submit the following information through a public issue or Pull Request:

- Passwords
- API keys
- Access tokens
- Private keys
- Database credentials
- Authentication credentials
- Personal sensitive information

If you accidentally commit sensitive information, report it immediately and rotate/revoke the exposed credential.

## Security Updates

Security-related issues will be reviewed and addressed as appropriate.

Thank you for helping keep the repository safe.
